# SimpleLive 2.0.25 · 弹幕发送与 Windows 直连更新

Git 标签：`tag25`。应用版本：`2.0.25+24025`。

## 弹幕发送

- 整合哔哩哔哩、斗鱼、虎牙、抖音的发送入口，统一文字输入、表情选择、发送状态和失败提示。
- 平台独立适配：哔哩哔哩使用表单接口，斗鱼使用认证长连接，虎牙、抖音复用官方网页登录态及平台发送流程。
- 依据平台真实响应确认发送，不以点击按钮或清空输入框代替成功；未确认结果保留提示与同文防重保护。
- 统一自己的弹幕突出显示，改善平台表情展示及哔哩哔哩表情预览比例。

## 连续输入更流畅

- 发送时保留输入焦点并选中已提交文本，下一次输入可直接替换为新草稿。
- 等待确认期间可以继续打字、选择表情；后到的发送结果不会清空已修改的新草稿。
- 修复同文重新输入、关闭输入区、切换房间时的草稿与晚到结果处理。
- 键盘聚焦也能触发已有发送连接准备，减少斗鱼首次提交时才开始认证的等待。
- 取消虎牙、抖音发送控件同步刷新遗留的布局计时器，减少重复网页扫描。
- 不引入自动排队、自动重发或并发刷送，保留平台原有冷却与限流判断。

## Windows 默认直连

- Dart HTTP 明确使用 DIRECT；WebView2 创建环境前禁用应用层代理，覆盖搜索及登录网页；mpv 禁用 HTTP 代理。
- 仅清理本软件进程内代理环境变量，不修改系统代理、FlClash 或其他软件配置。
- 保留既有登录数据、账号、收藏和历史记录；直接启动安装后的应用，无需外部脚本。
- 此项不阻断系统 VPN、TUN 或路由器层面的转发。

## 下载与安装

- `SimpleLive-2.0.25-windows-x64-setup.exe`：Windows x64 安装包，推荐使用。
- `SimpleLive-2.0.25-windows-x64-portable.zip`：完整便携版，解压后运行 `simple_live_app.exe`，不要只复制单个 exe。
- `SHA256SUMS.txt`：本次附件校验值。
- GitHub 页面下方 Source code 为 `tag25` 对应的完整仓库源码。

升级前正常退出正在运行的 SimpleLive，再安装新版。本版本没有用户数据结构迁移，不需要删除旧登录目录或配置。

## 测试与已知限制

- 应用测试：**578 通过，4 跳过**；核心库本地测试：**101 通过**。
- 核心库全量测试（含实网接口）：**135 通过，2 失败**。失败项是 B 站 `getCategoryRooms`（响应数据缺失导致读取 `has_more` 失败）和抖音 `searchRooms`；本次未修改这两个读取接口，不将其标记为已修复。
- Windows Release 重新构建成功，程序及安装包版本均为 **2.0.25**；安装包内 54 个文件与 Release 构建逐一校验一致。
- 浏览器本地夹具覆盖原生可信输入、平台响应判断、未就绪、失败、防重复和房间关联。
- 连续输入回归覆盖四个平台共同输入栏各 12 次顺序操作；这些是本地测试，不是公开直播间压测。
- 真实房间的发送速度提升比例、其他观众可见性、安装后逐屏操作及长期稳定性，本次发布未重新验收。不承诺缩短平台服务器确认耗时。
- 账号过期、未实名、禁言、验证码和平台限流仍可能阻止发送，应以界面显示的平台结果为准。
- 本 Release 仅提供已构建的 Windows x64 程序；未发布其他系统二进制。
